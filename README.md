# 电网业务研习室

一套面向软件研发人员的国家电网业务知识静态学习应用。当前包含前三章，不需要登录、数据库或后端服务。

课程以业务理解为主线，覆盖基础电力业务、营销服务、设备运检、计量采集、配电网拓扑、设备主人巡视和缺陷闭环。拓扑和接线使用本地 SVG 教学插图，设备科普使用本地化的真实照片，不依赖外部图片服务。

## 学习规则

- 首次打开只显示第01章。
- 一章的测验答对至少 2 题后，记为完成。
- 完成当前章节后，下一章立即解锁，不限制连续学习时间。
- 已完成的章节随时可以复习。
- 进度保存在当前浏览器的 `localStorage`，键名为 `sgcc-grid-learning-progress-v1`。
- 更换浏览器、设备或清理站点数据不会自动迁移进度。

## 本地预览

在应用目录运行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 服务器部署

将 `grid-learning` 目录中的全部文件复制到 Nginx、Apache、对象存储或其他静态站点目录即可。入口为 `index.html`，所有资源均使用相对路径，不需要额外配置接口或反向代理。

不建议直接双击 `index.html` 使用 `file://` 打开；通过 HTTP/HTTPS 部署可以避免不同浏览器对本地文件与 `localStorage` 的限制。

## 内容维护

- 章节、案例和测验位于 `assets/content.js`。
- 完成判定、顺序推进和章节选择位于 `assets/progress.js`。
- 页面交互位于 `assets/app.js`。
- 视觉样式位于 `assets/styles.css`。
- 教学插图位于 `assets/images/`。
- 真实设备照片位于 `assets/images/real/`，来源和许可见同目录 `CREDITS.md`。

新增章节时，在 `chapters` 数组末尾添加结构相同的章节对象，并更新新增章节的 `next` 字段即可。课程总数和进度会自动按数组长度计算。

### 内容编写约定

- 专业术语首次出现时，要先用通俗语言说明“是什么”，再给常见现场例子。
- 容易混淆的词要明确对照，例如供电点、计量点、公变、专变、缺陷、故障。
- 解释业务状态时，要说明谁会使用这个结果，以及判断错误会影响客户、计量、运检还是后续作业。
- 数字和参数要带单位，并说明它是额定值、实时值、累计值还是业务上限。
- 涉及省公司差异、现场制度和分类口径时，明确提示需要核实，不写成全国统一规则。
- 正文以业务理解为主，不用数据库结构、接口 JSON 或技术实现替代业务解释。
